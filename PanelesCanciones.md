# Paneles de Canciones 

Las operaciones realizadas con las canciones son con los dos tipos de canciones **Cancion individual**  
y **Colaboración**. 

### Operaciones con canciones 

* Agregar canciones
* Eliminar canciones
* Modificar canciones
* Agregar colaboraciones
* Eliminar colaboraciones
* Modificar colaboraciones

## Paneles de canciones 

* **MenuCancionIndividual**: Menú para elegir las operaciones para trabajar con una canción individual, agregar una 
canción individual, eliminar una canción individual y modificar una canción individual.
* **AgregarCancionIndividual**: Panel para agregar una canción individual, donde se agrega un título, una descripción, una 
duración siguiendo un formato de tiempo, el ID del artista de la canción, el álbum donde 
pertenece y un género de una lista de géneros.
* **EliminarCancionIndividual**: Panel para eliminar una canción individual por medio de su ID.
* **ModificarCancionIndividual**: Panel para modificar los datos de una canción individual de forma independiente y por medio 
de su ID.
* **MenuColaboracion**: Menú para las operaciones relacionadas con una colaboración, cómo agregar una 
colaboración, eliminar una colaboración y modificar los datos de una colaboración.
* **AgregarColaboracion**: Panel para agregar una colaboración, agregando datos como su título, su descripción, una 
duración en un formato de tiempo, el ID del artista principal, el ID del segundo artista 
colaborador, el ID del álbum al que pertenece, un género de una lista de géneros y una fecha 
de colaboración siguiendo un formato de fecha.
* **EliminarColaboracion**: Panel para eliminar una colaboración por medio de su ID.
* **ModificarColaboracion**: Panel para modificar los datos de forma individual de una colaboración, por medio de su ID.

## Metáforas 

1. Para la **canción individual** se debe pensar en que es una melodía compuesta por un 
solo artista, por lo que se debe pensar en metáforas que recuerden a la música misma, 
en este caso, se estará utilizando una nota musical para representar música, pero en 
este caso, se trabaja con canciones.
2. A diferencia de una canción, la **colaboración** es llevada a cabo por 2 artistas. De la 
misma manera que con el artista grupal, la metáfora elegida para la colaboración 
fueron 2 artistas que cantan notas musicales, quiere decir que 2 artistas hacen una 
canción.
