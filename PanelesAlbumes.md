# Paneles de Álbumes 

Los paneles que se crearon para los álbumes son los mismos que para casi todas las entidades  
de manera que se realicen altas, bajas y modificaciónes. 

### Operaciones con los álbumes 

* Altas de álbumes
* Bajas de álbumes
* Modificación de los datos de un álbum

## Paneles 

* **MenuAlbum**: Menú principal para las operaciones con los álbumes, cómo agregar un álbum, eliminar un 
álbum y modificar los datos de un álbum.
* **AgregarAlbum** Panel para agregar un álbum, agregando un título, una fecha de lanzamiento por medio de un 
calendario de Java y el ID del artista propietario.
* **EliminarAlbum**: Panel para eliminar un álbum y todo su contenido por medio de su ID.
* **ModificarAlbum**: Panel para modificar los datos de un álbum de forma individual.

## Metáforas de diseño 

1. Un álbum puede contener canciones, por lo que generalmente se le puede asociar 
con un objeto que contenga varias canciones, y como para una canción se pensó en 
un disco de vinilo y después una nota musical, se pensó en un empaque físico de un 
disco de vinilo, esto para dar a entender que es el contenedor de una o más 
canciones.
