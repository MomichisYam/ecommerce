# Menú Principal

La interfaz de menú principal sirve como la única pantalla de MusicPedia  
ya que, aquí es donde se cargan Paneles, dentro de los paneles se muestran  
todos los menús para bajas, altas y modificaciones de las 3 entidades  
principales de MusicPedia, que son Artistas individuales, Artistas grupales,  
Canciones y Álbumes. 

## Cintas y botones 

Las cintas de MusicPedia se encuentran a la izquierda y a la derecha,  
donde en la izquierda se encuentran los botones para entrar a cada uno  
de los menús de cada entidad, y en la derecha se encuentra una cinta  
de botones para poder ver las tablas con los datos de la base de datos. 

Los botones que se encuentran son los botones que tienen un ícono para 
asociar cada una de las entidades, mientras que para abrir las tablas  
se muestra un texto con el nombre de la tabla a visualizar los datos.  


## Panel de acción 

El panel de acción es donde se mostrarán los paneles donde se trabajarán   
cada una de las pantallas, siendo una opción sencilla de reemplazar una  
pantalla por otra, además de que dentro de los paneles servirá de   
contenedor para todos los label, botones, textfields etc.  

## Tabla 

La tabla es el espacio donde se mostrarán todos los datos de cada  
entidad, teniendo un espacio para cargar una tabla a la vez,  
cada tabla tendrá tantas columnas como atributos tenga una entidad  
de la base de datos.
